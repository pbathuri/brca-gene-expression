# Weekly evidence rubric (100 points)

| Criterion | Points | Evidence |
|---|---:|---|
| Data provenance and QA | 20 | Frozen source register, data contracts, exclusions |
| Method correctness | 25 | Hand check, assumptions, baseline and meaningful tests |
| Evaluation and uncertainty | 20 | Appropriate comparison and sensitivity analysis |
| Reproducibility and teamwork | 20 | Clean rerun, reviewed PRs, environment and run records |
| Communication | 15 | Readable plots, honest limitations, focused demo |

Each student demonstrates one calculation, reviews another student's PR and explains one design choice. A polished dashboard cannot compensate for untraceable data or leakage. A null biological result can be a successful project if the analysis is sound.

Final talk: 6 slides, 7 minutes plus 3 minutes of questions. Question → data/cohort → method → two findings → limitations → demonstration/next step. Each student speaks. Attach a one-page methods note and a contribution table. Findings must come from approved real inputs; if access failed, present a methods prototype and label it honestly.
